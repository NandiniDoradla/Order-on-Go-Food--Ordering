# OrderOnTheGo - Food Ordering Web Application

## Overview

OrderOnTheGo is a modern food ordering web application that allows users to browse restaurants, explore menus, add food items to their cart, and place orders online. The platform provides a seamless and user-friendly experience for customers while enabling efficient order management.

## Features

### User Features

* User Registration and Login
* Browse Restaurants and Food Categories
* Search for Food Items and Restaurants
* View Detailed Food Information
* Add Items to Cart
* Update Cart Quantity
* Place Orders Online
* View Order Summary
* Responsive Design for Mobile and Desktop

### Admin Features

* Manage Food Items
* Manage Restaurants
* View Customer Orders
* Update Order Status
* Manage Users

## How It Works

1. Users register or log in to the application.
2. Browse restaurants and available food items.
3. Add desired items to the shopping cart.
4. Review cart details and proceed to checkout.
5. Place the order successfully.
6. Admin can view and manage incoming orders.

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Install frontend dependencies:

```bash
cd client
npm install
```

3. Install backend dependencies:

```bash
cd server
npm install
```

4. Configure MongoDB connection.

5. Start the backend server:

```bash
npm start
```

6. Start the frontend:

```bash
npm start
```
